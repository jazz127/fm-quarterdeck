# Preserving parked work

This is an optional migration procedure, not an inventory of an installation.

Before retiring a development checkout, its owner records the requested intent, exact source identity, tracked/untracked disposition, validation limits, unresolved decisions and private runtime owners in a private handoff. Preserve original refs and user data until their disposition is explicitly approved. A stopped process or retained checkout is not proof of completion, publication or deployment.

Separate source preservation from runtime preservation. Do not put operational handoffs, account diagnostics, browser profiles, logs or transcript pointers into a public source tree. Use the [branch contract](branching-and-preview-model.md) for promotion authority and the [private runtime guide](PRIVATE-RUNTIME.md) for data ownership. An archive of reviewed tracked source is not a backup of private runtime state.
