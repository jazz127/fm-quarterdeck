# Code of conduct

This policy applies to project issues, pull requests, reviews and other project-managed spaces. Participants should be respectful, patient and constructive. Discuss code and ideas with evidence, welcome different experience levels, and respect people's boundaries and privacy.

Harassment, discrimination, threats, sexualized conduct, personal attacks, impersonation and publishing another person's private information are unacceptable. Do not post credentials, private runtime data or sensitive security details.

The repository owner or designated maintainers may edit or remove harmful content, warn participants, restrict participation or exclude participants for serious or repeated violations. They should explain decisions when safe, consider context fairly, and limit disclosure of reports to people needed to handle them. No response-time guarantee is promised.

Report conduct concerns privately through the confidential conduct contact advertised by the public repository's maintainer. That contact must be established before public contributions open; this private preparation tree does not advertise one yet. If it is unavailable, request a private contact without posting identities or incident details publicly. Maintainers must offer an alternative contact for complaints involving the primary contact. Security vulnerabilities use the separate route in [SECURITY](SECURITY.md).
